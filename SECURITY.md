# Security Policy

| Version | Supported |
| --- | --- |
| 1.x | ✔️ |
| 0.x | ❌ |

## Reporting a Vulnerability

Security is a priority for this project and responsible disclosure is appreciated. If you discover a vulnerability, please report it privately rather than opening a public issue.

You can report security concerns by contacting me through GitHub or by email in the repository profile. I will acknowledge receipt as quickly as possible and will keep you informed as the issue is reviewed and addressed.

Clear reproduction steps, affected components, and any relevant logs or proof‑of‑concept details help speed up the investigation. If the vulnerability is confirmed, a fix will be prepared and released in a timely manner.
