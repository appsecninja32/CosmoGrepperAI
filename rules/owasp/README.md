# GlorifiedGrepper OWASP Rulepack

This directory contains the full multi-language OWASP-style rulepack used by the
GlorifiedGrepper AppSecNinja32 scanning engine.

## Features

- One file per language (no cross-language parse errors)
- All rules are ASCII-only and Windows-safe
- No registry rules or Unicode dependencies
- Compatible with Semgrep on Windows
- Covers 30+ languages
- Includes OWASP-style checks for:
  - Injection
  - Command execution
  - Weak crypto
  - Hardcoded secrets
  - Debug/logging issues
